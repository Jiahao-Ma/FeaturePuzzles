## 2. 数据集概述

SA-1B 是大规模图像分割数据集，核心关注点是：

1. 每张图片对应的标注数量。
2. 标注区域的面积与分布情况。
3. 标注质量相关字段，如 `predicted_iou` 与 `stability_score`。
4. 图像与标注是否能够稳定读取并完成可视化。

### 本地数据路径

当前确认的数据路径为：

`/mnt/dataset/marko/data/sa1b/data/sa_000000/`

### 当前已确认的数据组织形式

1. 数据以分片目录组织。
2. 每张图片对应一个同名 JSON 标注文件。
3. 单个 JSON 文件中包含图片信息与多个 annotations。

## 3. 已确认的数据字段

当前已经确认 SA-1B 样本主要包含以下信息：

| 字段 | 说明 |
|------|------|
| `image.image_id` | 图片唯一标识 |
| `image.width` / `image.height` | 图片尺寸 |
| `image.file_name` | 图片文件名 |
| `annotations[].bbox` | 标注框 |
| `annotations[].area` | 标注面积 |
| `annotations[].segmentation` | 分割掩码信息 |
| `annotations[].predicted_iou` | 预测质量分数 |
| `annotations[].point_coords` | 生成掩码相关点坐标 |
| `annotations[].crop_box` | 生成掩码时的裁剪区域 |
| `annotations[].id` | 标注唯一标识 |
| `annotations[].stability_score` | 掩码稳定性分数 |
